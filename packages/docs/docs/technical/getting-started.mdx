# Getting Started with Kite Dialog

The Kite Dialog component provides an accessible, responsive modal dialog solution for your React applications. This guide will help you get up and running quickly.

## Installation

<Tabs>
  <TabItem value="npm" label="npm" default>

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

</Tabs>

## Basic Usage

Here's a simple example of the Dialog component in action:

```jsx
import React, { useState } from "react";
import { Dialog, DialogBody, DialogActions } from "@kite/Dialog";

function YourComponent() {
  const [isOpen, setIsOpen] = useState(false);

  const handleOpen = () => setIsOpen(true);
  const handleClose = () => setIsOpen(false);

  return (
    <>
      <button onClick={handleOpen}>Open Dialog</button>

      <Dialog
        open={isOpen}
        onClose={handleClose}
        title="Example Dialog"
        titleIcon={<p>😎</p>}
      >
        <DialogBody>
          <p>
            This is a basic dialog example that demonstrates the core
            functionality. You can customize the content, title, and actions to
            suit your needs.
          </p>
        </DialogBody>
        <DialogActions>
          <button onClick={handleClose}>Cancel</button>
          <button onClick={handleClose}>Confirm</button>
        </DialogActions>
      </Dialog>
    </>
  );
}
```

## Component Structure

The Dialog component is composed of several parts: 
1. `Dialog` - The main wrapper component 
2. `DialogTitle` (optional) - Dynamic title structure. Needs this or `title` prop 
3. `DialogBody` (optional) - Contains the dialog content. SHOULD BE USED.
4. `DialogActions` (optional) - Container for action buttons
5. `DialogButton` (optional) - core DialogButton. No buttonType allows personal stylistic customization with automatic onClose callback
6. `DialogSuccessButton` (optional) - Provides "success" to `onComplete` callback. DialogButton with buttonType 'success' 
7. `DialogFailureButton` (optional) - Provides "failure" to `onComplete` callback. DialogButton with buttonType 'failure' 
8. `DialogCloseButton` (optional) - Calls `onClose` callback. DialogButton with buttonType 'close'
